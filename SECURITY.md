# Security

Please report a vulnerability privately to **ghostline@vorivant.com**, not in a public issue. Say which version and
platform you used and how to reproduce it. We aim to answer within a week and to credit reporters who want it.

Releases come with `SHA256SUMS` signed by an SSH signing key whose public key is published on the download page.
Check the signature and the checksum before installing (the download page shows the commands).

Upstream issues in the Tailscale client or Headscale are fixed upstream; tell us too, so that Ghostline can pick up
the fix.
